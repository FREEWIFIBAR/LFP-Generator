# LFP-Generator
Este proyecto consiste en el desarrollo de un procesador de fórmulas de lógica proposicional utilizando Java. Su objetivo es analizar, interpretar y transformar expresiones lógicas mediante las principales técnicas empleadas en el diseño y desarrollo de compiladores.

El sistema permite procesar ficheros de entrada que contienen teorías y fórmulas lógicas, realizar su análisis léxico y sintáctico, construir árboles de sintaxis abstracta (AST), aplicar reglas de simplificación y transformar las expresiones a Forma Normal Clausal (FNC).

Además, incorpora herramientas como JavaCC para la generación automática de analizadores y GraphViz para representar gráficamente los árboles sintácticos.
